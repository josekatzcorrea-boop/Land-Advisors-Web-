Vincular +56974533265 con Cloud API

Flujo oficial de coexistencia: mantienes WhatsApp Business en el celular y activas la API para el bot.

Antes: actualiza WhatsApp Business a la última versión. Ten el celular con +56974533265 a mano.

Si el popup se cierra solo

Antes de reintentar, en Meta Developers → W API → Inicio de sesión con Facebook para empresas → Ajustes:

  1. Dominios de la app → agrega localhost
  2. URI de redireccionamiento OAuth válidos → agrega http://localhost:8787/coexistencia
  3. Guarda cambios

O usa el builder oficial de Meta (más estable):
Abrir Embedded Signup Builder en Meta

  1. Meta abre un popup (inicia sesión si hace falta).
  2. Elige conectar cuenta existente de WhatsApp Business (no crear número nuevo).
  3. En el celular puede llegar un mensaje de Facebook Business con botón Conectar.
  4. Al terminar, el número queda CLOUD_API + app del celular.
